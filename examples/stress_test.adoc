Stress Tester <test@example.com>

:pdf-page-size: Letter

This document deliberately exercises every layout scenario that has
historically caused overlap, clipping, or mis-sizing in the PDF back-end.
Each section targets a specific risk area so that a visual or automated
diff will immediately reveal regressions.

== 3. Admonitions
// ─────────────────────────────────────────────────────────────────────────────

Each admonition type is shown below.  The label column and the body column
must align; no label text should overflow into the body column or vice-versa.

NOTE: This is a NOTE admonition.  It should have enough vertical clearance
above the next paragraph so that no overlap occurs.

TIP: This is a TIP admonition.  Tips should look identical in structure to
notes, only the label text differs.

WARNING: This is a WARNING admonition.  The label is longer than NOTE and
TIP; make sure the indent is consistent.

IMPORTANT: This is an IMPORTANT admonition.  The label is the longest in the
standard set.

CAUTION: This is a CAUTION admonition.
